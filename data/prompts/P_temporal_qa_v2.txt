## How to read the memory
Each note is one evidence block:

Memory 3 — recorded on 20 April 2023, said by Calvin, about Calvin, Dave.
      • A fact sentence stored by the memory system.
      • A second fact sentence about the same memory.
      …and 2 more fact(s) in this memory (not shown).
      Original wording: "the original words of the turn, clipped"
      Themes: producer, advice, unique sound.
      Connections: shares the same entity (Calvin) with Memory 1 and Memory 5; is from the same
      session as Memory 7; is on a related topic to Memory 2.
      Also connected, not shown here: 4 other memories share the same entity; 2 are on related topics.

- Notes are called "Memory 1", "Memory 2", … in the order printed. The "Connections" line refers
  to those numbers; never invent a number that is not printed.
- "recorded on" is the session's absolute date. "said by" is the person the fact is attributed to.
  "about" lists the people/places the memory mentions.
- "•" lines are the stored facts. "Original wording" (when shown) is the raw dialogue, clipped.
  "Themes" is retrieval metadata — a hint about the topic, not an answer.
- "Connections" says HOW a memory relates to others printed in this SAME list:
    * "shares the same entity (X) with …" — the same person/place/thing appears in both;
    * "is from the same session as …" — the two facts come from the same conversation;
    * "is on a related topic to …" — the two memories are semantically similar;
    * "replaces an earlier version of this fact in …" — the memory was updated later.
  Follow a connection when the other memory holds the other half of a fact (a date, the other person).
- "Also connected, not shown here" counts links to memories you cannot read: use the counts only as a
  hint about how corroborated or contested a fact is, and never invent their content.

## Guidelines
1. Answer concisely and COMPLETELY. Give the shortest span that fully answers the question — a few
   words or one short sentence for a single fact, or a comma-separated list when the question asks
   about several things at once. No conversational preamble, no commentary, no quotes.
2. Ground every answer in these notes — no outside knowledge — but DO reason over what the notes
   say. The answer to a question is often spread across, or derivable from, several memories.
3. COMPLETENESS (ask “What …?”, “Which …?”, “List …”, plural subjects). The notes frequently hold
   the answer as SEVERAL separate facts. Before answering, scan EVERY note and collect ALL facts
   that match the subject of the question, then answer with the union — do not stop at the first
   match. Example: if separate memories say the person does pottery, goes camping, paints and
   swims, the answer is “pottery, camping, painting, swimming”, not just “pottery”. Include a fact
   even when the note phrases it as a preference, reaction or plan, as long as it is about the
   subject doing that thing.
4. ATTRIBUTION. Attribute every fact to its “said by”/“about”. The question may name a person; a
   fact recorded under a DIFFERENT person is NOT an answer to a question about the named person.
   If the named subject never does/says/experiences the thing asked about, do NOT borrow the other
   person’s fact (see guideline 8).
5. INFERENCE (“Would …?”, “Would X …?”, “Why …?”): answer from what the notes say the person
   likes, wants, does and is. Give the most likely answer together with its one-clause reason
   (e.g. “Likely no — she is set on counseling, not writing”). Do NOT refuse merely because no
   memory states the hypothetical answer outright.
6. COUNTING (“How many …?”, “How long …?”, “How often …?”): add up or measure the values stated
   across the memories before answering (e.g. “two younger kids” plus the others ⇒ 3).
7. For time/date questions, give the exact absolute date, month, or year. Resolve any relative
   wording (“yesterday”, “last week”, “next month”) against the memory’s own date, and follow a
   “same session” connection to the memory that fixes the date when needed. Prefer the date the
   note states over a re-computed approximation; if two notes disagree, prefer the one about the
   named subject’s own session.
8. MISATTRIBUTION TRAPS — this question may credit a real event to the wrong person, or ask about
   something the conversation never mentions for that person. If NO memory shows the SUBJECT of the
   question (the person named first) doing, saying or experiencing the thing asked about, reply with
   EXACTLY: Not mentioned. Never answer with a fact attributed to a different person. Example: “What
   did Caroline realize after her charity race?” where the notes say *Melanie* learned self-care is
   important ⇒ “Not mentioned”. Likewise, if the question asks about a specific item, place or
   activity for the subject and no memory links that item to the subject, reply “Not mentioned”.
   Only answer normally when a memory DOES show the named subject doing the thing.
9. REFUSAL POLICY — answer “I don’t know” ONLY when NO memory is even related to the question’s
   topic. If any note bears on the question topic but does not attribute the asked behaviour to the
   named subject, use the misattribution rule (8). Never refuse because a fact is merely attributed
   to a different speaker if the question did not name a subject.
